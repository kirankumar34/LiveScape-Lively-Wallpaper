# 📦 Installation

### Clone Repository

```bash
git clone https://github.com/kirankumar34/LiveScape-Lively-Wallpaper.git
```

### Load Extension

```text
chrome://extensions
```

1. Enable Developer Mode
2. Click Load Unpacked
3. Select Project Folder
4. Open a New Tab

Done 🎉
